# @fv/driver — Driver app

Expo (SDK 52) driver scaffold with expo-router (stack + tabs).

## Screens

- Login
- Assigned Orders
- Order Detail (OTP + Proof of Delivery stubs)
- Earnings
- History

API base URL: `expo-constants` `extra.API_URL` or `EXPO_PUBLIC_API_URL`.

## Run

```bash
pnpm --filter @fv/driver start
```
